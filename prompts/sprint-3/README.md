## Architecture Rules

Read before every implementation:

- docs/
- docs/adr/
- CodingRules.md

The documentation is authoritative.

Implement one module at a time.

Do not anticipate Sprint 4.

Each module must include:

- migration
- repository
- repository interface
- application service
- API
- schemas
- events
- README
- unit tests
- integration tests

Stop after each module.
