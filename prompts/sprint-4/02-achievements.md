# Module 2 – Achievements

Implement the Achievement module.

Responsibilities

- Achievement definitions
- Progress tracking
- Hidden achievements
- Badge metadata
- Achievement repository
- APIs

Consume

- ChallengeCompleted
- ProgressUpdated
- TrophyAwarded

Publish

- AchievementUnlocked

Requirements

- Multi-stage achievements
- Incremental progress
- Idempotent processing
- Repository owned by Achievement module

Do not implement

- Leaderboards
- Notifications
- Analytics

Deliverables

- Domain
- Repository
- Service
- API
- Event Handlers
- Tests
- Documentation
